# Aboard 進階說明

## 1. 繪圖與互動
- 畫布繪製以原生 Canvas 為核心。
- 筆觸、形狀、選取、沿邊繪圖分別拆到不同模組，降低耦合。
- 為了在高倍率縮放下保持清晰，現在會額外同步一層 SVG 向量預覽；文字、圖片、筆跡與形狀在放大查看時會優先顯示 SVG 結果，而匯出仍沿用既有 Canvas 流程。
- 選取框、旋轉、縮放、圖片控制等疊加層透過獨立樣式與控制邏輯處理。

## 2. 狀態、歷史與恢復
- `js/history.js` 負責復原與重做。
- `js/modules/storage-manager.js` 負責 IndexedDB / 本地儲存的持久化與恢復。
- `settings-manager` 集中管理工具列大小、主題、語言與可匯出的設定。
- 快取占用統計現在會優先使用 `navigator.storage.estimate()`，不可用時再回退到手動估算，並透過請求令牌避免非同步結果覆蓋，防止清理後仍顯示舊數值。

## 3. 時間、計時器與課堂工具
- 時間顯示與計時器各自擁有獨立模組與樣式檔，避免互相污染。
- 點名器、計分板、教具屬於「課堂輔助層」，與核心繪圖引擎解耦。
- 「更多功能」面板只保留入口角色，實際邏輯盡量留在對應模組中。

## 4. 文件與翻譯維護建議
- 新增複雜功能時，優先補 `docs/`，README 只保留入口級資訊。
- 新增語言 key 時，先更新對應 locale，再檢查 `js/locales/overrides.js` 是否仍需補丁。
- 如果某個語言介面仍出現其他語言內容，優先檢查：
  1. 是否漏了 `data-i18n`；
  2. locale 是否缺 key；
  3. 動態建立的 DOM 是否在切換語言後重新翻譯。
- 這次新增的「恢復大小 / 保持置中」按鈕與可勾選的快取清理確認框，就是需要同步補齊全部 locale 的典型例子。

## 5. 部署與除錯
- 本地開發可直接使用 `node server.js` 或 `npm start`。
- `version.txt` 與 `/api/version` 用於版本顯示與更新檢查。
- 離線能力與快取行為由 `sw.js` 與 `pwa-manager` 協同處理。

## 6. 建議後續方向
- 為關鍵互動補上 Playwright 冒煙測試。
- 持續把硬編碼 UI 文案搬進 locale 體系。
- 進一步拆分 `main.js` 裡的初始化與事件綁定邏輯。
