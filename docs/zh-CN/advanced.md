# Aboard 进阶说明

## 1. 绘图与交互
- 画布绘制以原生 Canvas 为核心，笔触、形状、选择、沿边绘图分别拆到不同模块。
- 工具切换由 `main.js` 统一协调，避免每个功能都直接改全局状态。
- 选中态、旋转、缩放、图像控制等 UI 叠加层通过独立样式与控制逻辑处理。

## 2. 状态、历史与恢复
- 历史记录由 `js/history.js` 管理，负责撤销/重做。
- 本地恢复与持久化由 `js/modules/storage-manager.js` 配合 IndexedDB / 本地存储完成。
- 设置项由 `settings-manager` 集中管理，这样工具栏大小、主题色、多语言等都能统一读取与导出。
- 缓存占用统计现在会优先使用 `navigator.storage.estimate()`，不可用时再回退到手动估算，并通过请求令牌避免异步结果覆盖，防止清理后仍显示旧数值。

## 3. 时间、计时器与课堂工具
- 时间显示与计时器都拆成独立模块与独立样式文件，减少互相污染。
- 点名器、计分板、教具等属于“课堂辅助层”，与核心绘图层解耦，便于按需维护。
- “更多功能”面板只负责入口，真正逻辑尽量放在对应模块里。

## 4. 文档与翻译维护建议
- 新增复杂功能时，优先补 `docs/`，README 只保留入口级信息。
- 新增语言 key 时，先改对应 locale，再检查 `js/locales/overrides.js` 是否还需要补丁。
- 如果某个语言界面仍出现其他语言内容，优先检查：
  1. `data-i18n` 是否缺失；
  2. locale 文件是否漏 key；
  3. 动态生成的 DOM 是否在语言切换后重新翻译。
- 这次新增的“恢复大小 / 保持居中”按钮与可勾选的缓存清理确认框，就是需要同步补齐全部 locale 的典型例子。

## 5. 部署与调试
- 本地开发直接使用 `node server.js` 或 `npm start` 即可。
- `version.txt` 与 `/api/version` 用于版本显示和更新检查。
- PWA、缓存与离线能力由 `sw.js` 和 `pwa-manager` 配合处理。

## 6. 推荐后续方向
- 为关键交互补充 Playwright 冒烟测试。
- 将更多硬编码 UI 文案迁移到 `data-i18n` + locale 体系。
- 继续拆分 `main.js` 中的初始化与事件绑定逻辑。
