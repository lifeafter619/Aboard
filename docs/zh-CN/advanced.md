# Aboard 进阶说明

## 1. 绘图与交互
- 画布绘制以原生 Canvas 为核心，笔触、形状、选择、沿边绘图分别拆到不同模块。
- 工具切换由 `main.js` 统一协调，避免每个功能直接改全局状态。
- 选中态、旋转、缩放、图像控制等 UI 叠加层使用独立逻辑与样式，方便单独维护和替换。

## 2. 状态、历史与恢复
- 历史记录由 `js/history.js` 管理，负责撤销与重做。
- 本地恢复与持久化由 `js/modules/storage-manager.js` 配合 IndexedDB / 本地存储完成。
- 设置项由 `settings-manager` 集中管理，工具栏大小、主题色、多语言等都能统一读取与导出。
- 缓存占用统计优先使用 `navigator.storage.estimate()`，不可用时再回退到手动估算，并通过请求令牌避免旧异步结果覆盖新状态。

## 3. 时间、计时器与课堂工具
- 时间显示与计时器拆成独立模块与独立样式文件，减少互相污染。
- 点名器、计分板、教具等属于“课堂辅助层”，与核心绘图层解耦，便于按需维护。
- “更多功能”面板只负责入口，真正逻辑尽量放在对应模块内部。

## 4. 文档与翻译维护建议
- 新增复杂功能时，优先补 `docs/`，README 保持入口级说明即可。
- 新增语言 key 时，先补对应 locale，再检查 `js/locales/overrides.js` 是否仍需要兼容补丁。
- 如果某个语言界面仍混入其他语言内容，优先检查：
  1. `data-i18n` / `data-i18n-*` 是否缺失；
  2. locale 文件是否漏 key；
  3. 动态生成 DOM 是否在创建后或语言切换后重新翻译。
- 动态按钮、浮动面板标题、帮助入口、状态文案最容易漏翻译，新增时最好顺手自检一遍。

## 5. 响应式与触控大屏维护建议
- 新增面板、浮动工具条、控制框时，优先保证：
  1. 主交互区域不少于 `44px × 44px`；
  2. 小对象上的手柄允许自动缩放，但必须设置最小尺寸下限；
  3. 当对象过小时，控件优先移入对象内部，而不是继续向外漂移；
  4. `pointer*` 事件优先，`mouse*` / `touch*` 作为兼容补充；
  5. 浮动面板在拖拽、缩放后仍要限制在可视区域内。
- 当前项目里，图片、选择框、笔迹框、插字框、教具叠加层等核心编辑控件都已经按上述思路做了自适应布局，可作为后续功能的模板。
- 如果后续新增复杂浮层，建议至少在以下场景做一次人工回归：
  - 1366×768 笔记本浏览器；
  - 1920×1080 教学一体机；
  - 2560×1440 / 4K 触控大屏；
  - 浏览器缩放 80%、100%、125%、150%。

## 6. 部署与调试
- 本地开发直接使用 `node server.js` 或 `npm start` 即可。
- `version.txt` 与 `/api/version` 用于版本显示和更新检查。
- PWA、缓存与离线能力由 `sw.js` 和 `pwa-manager` 配合处理。

## 7. 推荐后续方向
- 继续把零散硬编码 UI 文案迁移到 `data-i18n` + locale 体系。
- 持续拆分 `main.js` 中体量较大的初始化与事件绑定逻辑。
- 新增复杂交互前，先复用已有控件自适应与触控处理模式，避免重复造轮子。
